# Görev Yönetim Paneli

Bu proje, basit bir görev yönetim uygulaması örneğidir.

Frontend tarafında Next.js kullanılmıştır. Uygulama üzerinden görev listeleme, görev ekleme, görev güncelleme, görev silme, durum ve öncelik filtreleme işlemleri yapılabilir.

## Kullanılan Teknolojiler

- Next.js
- React
- TypeScript
- Tailwind CSS

## Özellikler

- Görev listeleme
- Görev ekleme
- Görev güncelleme
- Görev silme
- Duruma göre filtreleme
- Önceliğe göre filtreleme
